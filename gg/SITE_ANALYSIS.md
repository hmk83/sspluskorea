# SITE_ANALYSIS

## 분석 대상

- URL: https://prompts3.com/start/
- 성격: 한국어 AI 이미지 프롬프트 공개 카탈로그
- 핵심 흐름: 프롬프트 탐색 → 옵션 또는 문장 수정 → 프롬프트 복사 → 외부 AI 서비스에서 이미지 생성

## 원본 사이트 주요 구조

1. 시작 페이지
   - `복사 한 번으로 AI 이미지가 완성 됩니다`를 전면에 배치
   - 4,000개 이상 무료 한국어 프롬프트를 강조
   - 셀카 변신, 운세 분석, 매거진, 웹툰, 카페 포스터 등 대표 샘플을 롤링 카드로 노출

2. 카탈로그 페이지
   - 검색과 카테고리 필터 제공
   - 카드형 썸네일 목록 제공
   - 카드를 클릭하면 큰 미리보기, 프롬프트 직접 편집, 복사, ChatGPT 실행 기능 제공

3. 콘텐츠 데이터
   - `prompts.json` 기반으로 프롬프트 목록을 로드
   - 분석 시점 기준 총 4,120개 프롬프트 데이터 확인
   - 대표 카테고리: 프로필/아바타, 소셜 미디어, 인포그래픽, 유튜브 썸네일, 만화/스토리보드, 제품 마케팅, 이커머스, 게임 에셋, 포스터/전단, 앱/웹 디자인, 사진 변환, 소상공인 키트

## 원본 사이트의 장점

- 프롬프트 수가 많고 썸네일 기반 탐색이 빠르다.
- 한국어 사용자가 바로 이해할 수 있는 제목과 설명을 제공한다.
- 프롬프트를 직접 수정할 수 있어 초보자도 결과를 조정할 수 있다.
- 카테고리와 검색 구조가 명확하다.

## 개선 필요점

- 최종 이미지 제작은 외부 AI 서비스로 이동해야 한다.
- 프롬프트 수정 후 결과 확인까지의 흐름이 끊긴다.
- 생성 결과 히스토리, 비교, 다운로드 목적별 저장이 한 화면에 없다.
- 모바일에서 카탈로그 탐색과 생성 결과 관리가 한 화면 작업 도구처럼 이어지지 않는다.

## 이번 프로토타입 반영 방향

1. 외부 이동 없는 제작 흐름
   - 프롬프트 선택 후 같은 화면에서 이미지 생성 버튼을 제공한다.
   - 생성 결과는 아래 썸네일 영역에 하나씩 누적된다.

2. 직접 수정 유지
   - 원본처럼 한국어 프롬프트를 직접 수정할 수 있다.
   - 마음에 들지 않으면 문장을 바꾸고 다시 생성할 수 있다.

3. 큰 보기와 다운로드
   - 썸네일을 클릭하면 큰 보기 모달을 연다.
   - 웹용 PNG와 인쇄용 PNG 다운로드를 분리했다.
   - 웹용은 1200 x 1500, 인쇄용은 2640 x 3300으로 생성된다.

4. 샘플 10개 제공
   - 원본 공개 카탈로그에서 확인한 대표 유형 10개를 샘플로 구성했다.
   - 제목, 카테고리, 미리보기 이미지는 원본 공개 샘플 유형을 참고했다.
   - 긴 프롬프트 전문은 그대로 복제하지 않고 프로토타입용으로 새로 작성했다.

5. 반응형 최적화
   - PC: 좌측 카탈로그, 우측 편집/생성 패널 구조
   - 태블릿: 카탈로그와 편집 패널을 세로 흐름으로 전환
   - 모바일: CTA, 샘플 선택, 편집, 생성, 다운로드를 한 열로 정리

## 2차 반영 방향

1. 핀터레스트형 메인
   - 메인 카탈로그를 masonry 카드 피드로 변경했다.
   - 상단 검색, 카테고리 칩, 카드 전체 클릭 동작을 제공한다.

2. 상세페이지 전환
   - 카드를 누르면 홈과 목록을 숨기고 상세 제작 화면만 보이도록 변경했다.
   - URL은 `#detail=프롬프트ID` 형식으로 전환된다.

3. 제작 결과 위치
   - 상세 제작 화면 아래에 생성 이미지 히스토리가 이어지도록 유지했다.
   - 사용자는 상세에서 수정, 생성, 결과 확인, 다운로드까지 한 흐름으로 진행한다.
